# 实验记录

按时间顺序记录每一次尝试和结论。**失败的也记，因为失败的原因是可以复用的。**

---

## 阶段一：把台词从剧本里挖出来

剧情原文是脚本格式（`[name="..."]`、`[Dialog]`、`[Background]`），不是文章。直接当文本训会把舞台指令也学进去。

**做法**：先找现成的解析产物。`arknights-lore` 仓库的 Release 里有一份已经解析好的纯文本包（1943 个 `.txt`，27 MB），格式是「说话人：内容」。

**结果**：

```
1,943 个文件 → 387,007 条台词 → 6,689 个说话人
```

正确性旁证：说话最多的是 `？？？`(7,875)、阿米娅(7,094)、凯尔希(5,576)、陈(3,034) —— 和角色戏份对得上。

**阿米娅的 4 种写法**：`阿米娅`(7,094)、`"阿米娅"`(32)、`阿米娅？`(15)、`小阿米娅`(1)，合计 7,142 条，去重后 6,499。

**一个坑**：`？？？` 里有 7,875 条无名台词，序章里阿米娅还没自报家门，其中一部分是她说的。但无法可靠归属，只能放弃。

## 阶段二：自动分类（不手工）

6,228 条人工分类不现实。写词表规则，5 分钟跑完：

| 类别 | 条数 |
|---|---:|
| 剧情陈述 | 3,394 |
| 剧情设定 | 1,052 |
| 对博士 | 598 |
| 日常语气 | 536 |
| 战斗指挥 | 326 |
| 情绪柔软 | 178 |
| 日常关心 | 144 |

**噪声与取舍**：规则会误判（「日常关心」里混进了讲源石器官的句子，因为命中「身体」）。但训练时 95% 准确就够，不值得人工修。

**顺带发现的脏数据**：`阿米娅望着塔露拉。`、`卡特斯女孩没有回答你。` 这类**第三人称旁白**被挂在阿米娅名下，共约 200 条。用规则剔掉了，否则模型会学叙述腔。

## 阶段三：造训练对

### 失败的路：让模型反推问题

先有回答，再让 1.7B 猜「博士会问什么」。**质量太差，放弃。**

```
答：你们一定要平安无事......     → 问：你一定要平安无事吗？
答：但是我不在乎。              → 问：你是否认为责任是被强加的？
```

问题：只是在原句上打转、格式污染（出现「序号. 」）、问答错位。

**根因**：1.7B 做不了「语义反推」这种需要理解意图的任务。

### 成功的路：捡现成的对话回合

原文里，阿米娅的上一句若不是她自己说的，那就是一个真实回合。

```
凯尔希：暴行的报告我看过了。
阿米娅：是，凯尔希医生。
```

零生成成本、语境真实，拿到 **1,588 条**。

**局限**：对方多是 NPC（凯尔希 94、陈 85、暴行 60……），直接跟在博士后面的只有 43 条 —— 因为游戏里玩家角色走的是选项，不是台词。

## 阶段四：v1 —— 人设成了，话太短

| 项 | 值 |
|---|---|
| 数据 | 1,588 条单句对话 |
| LoRA | rank 8, alpha 16, target=all |
| 步数 | 1,131（3 epoch） |
| train / eval | 2.9 / 3.16 |

**好的**：

```
帮我写一个 Python 快速排序 → 我……我不会。
我今天好累，不想干活了     → ……没关系，我来帮你。
```

**坏的**：回答只有 5~10 字，训练集中位是 15 字，它偏在最短一端。

**后来发现更坏的**：训到 3 epoch 后模型开始坍缩 —— 七句回答里六句以「…… 」开头，且「我不会」变成了「我给你写一个吧」。**人设被模板覆盖了。**

---

## 阶段五：v2 —— 合并长句 + 档案问答，崩了

两个改动同时上：

1. 连续台词合并成段落（2,749 段 → 过滤后 2,186 条）
2. 人物/势力档案转成问答（300 条）

| 项 | 值 |
|---|---|
| 数据 | 2,486 条 |
| 步数 | 590 |
| train / eval | 3.2~3.6 / 3.19 |

**结果：12 个 checkpoint 里 9 个在无限复读**

```
给我讲讲罗德岛 → 罗德岛，罗德岛，罗德岛，罗德岛......
赫默是谁       → 赫默，罗德岛干员，罗德岛干员，罗德岛干员......
```

**排查**：训练集内部重复率只有 0.1%，不是抄来的。真因是**句式重复** —— 300 条档案答案全是「名字，属性，属性，属性。」同一个结构，模型学的是这个格式，贪心解码下自我强化。

**关键认知**：不是比例问题，是可预测性问题。模板句 loss 天然低，每一步贡献最稳定的梯度，**12% 的数据能干翻 88% 的数据**。

---

## 阶段六：v3 —— 去掉档案，做对照

只改一处：删掉那 300 条。

| | v2 | v3 |
|---|---|---|
| 循环起点 | 第 100 步 | 第 150 步 |

**定罪成功**：档案数据确实是主因。但 v3 到 150 步后仍在知识题上循环，说明还有第二个因素 —— 合并后的长文本让模型学会「靠重复关键词续写」。

**而且人设没立住**：

```
帮我写快排 → 嗯，我来写一个快速排序的代码。首先，我需要定义一个函数……
```

跑到 519 步（满一轮）也一样。**知识题从 250 步到 519 步，一个字都没变**：

```
凯尔希医生是谁 → 凯尔希医生是......
```

---

## 最终判断

| 版本 | 人设 | 长度 | 循环 | 知识 |
|---|---|---|---|---|
| v1 | **强** | 短 | 后期有 | 无 |
| v2 | 崩 | 长 | **严重** | 有（但毁了一切） |
| v3 | 弱 | 长 | 中 | 无 |

**这是跷跷板**：短句教「一句话怎么回」，长句教「连续叙述」。为了治话短，把「干脆」也治没了。

**结论**：
- 台词数据能教语气，教不了知识 —— 知识必须走 RAG
- 低熵的模板数据不能进训练集，哪怕只占 12%
- 小数据微调的最优训练量很窄，v1 的 1~2 epoch 之间是甜点，3 epoch 必崩

**交付版本**：v1 的 checkpoint-200。
